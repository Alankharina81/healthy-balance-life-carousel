# Healthy Balance Life — Carousel Studio

Template sederhana untuk membuat carousel Instagram edukasi Healthy Balance Life.

## File proyek

- `index.html` — halaman editor dan pratinjau carousel.
- `style.css` — gaya antarmuka dan desain slide.
- `app.js` — contoh konten, editor 5 slide, navigasi, dan ekspor PNG.

## Cara menggunakan

1. Buka `index.html` di browser, atau aktifkan GitHub Pages untuk mengaksesnya sebagai website.
2. Ubah topik dan pengantar pada bagian atas editor.
3. Ubah judul dan isi edukasi pada slide 2–5.
4. Pilih slide dengan tombol navigasi atau thumbnail.
5. Klik **Unduh 5 slide PNG** untuk mengunduh seluruh slide.

Ekspor PNG memerlukan koneksi internet karena library `html-to-image` dimuat melalui CDN.

## Sistem desain

- Rasio desain: 4:5.
- Target ekspor: 1080 × 1350 px.
- Latar: `#f6f5f2`.
- Teks / outline: `#2d336b`.
- Aksen lavender: `#a5b4fc`.
- Highlight: `#ffcc33`.
- Bahasa: Bahasa Indonesia.
- Audiens utama: perempuan Indonesia usia 35+.
- Identitas: Healthy Balance Life · Coach Kharina.

## Pengembangan selanjutnya

Template ini adalah fondasi awal. Sebelum konten dipublikasikan, periksa akurasi informasi kesehatan, keterbacaan, dan konsistensi visual setiap slide.
